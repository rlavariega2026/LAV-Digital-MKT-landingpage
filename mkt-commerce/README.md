# Comercio LAV Digital MKT — México
Catálogo y tarifas: mkt-commerce/catalog.json. No se alteran precios de servicios. Los servicios sujetos a alcance personalizado conservan cotización. Carrito con cantidades y opciones de displays.
Envíos físicos: Mexpost 150/170/190/200/210/220/230 MXN, Estafeta 335 MXN. Sin costo para pedidos digitales. Los destinos sin zona vial/cobertura validadas no pueden pagar automáticamente; pueden confirmar por WhatsApp.
Mercado Pago Checkout Pro: copiar el ejemplo de configuración fuera de public_html como lav-mkt-commerce-config.php, proporcionar credenciales propias de producción, ID del vendedor y firma secreta de Webhooks. Habilitar evento payment; URL https://lavdigitalmkt.com/mkt-commerce/api.php?action=webhook&source_news=webhooks . Probar con credenciales de prueba antes de producción. Habilitar solo tras confirmar pesos, CP y cobertura. No introducir credenciales en el navegador, repositorio o chat. Los pedidos se almacenan fuera del directorio público. No se considera pago aprobado hasta verificar referencia, moneda, importe y vendedor mediante API.

Orders API: POST /v1/orders con idempotencia; GET /v1/orders/{id} para verificar. `environment=test` mantiene los cobros públicos bloqueados, incluso si enabled=true. Para acceder a la prueba, establecer test_key aleatoria privada (20+ caracteres) y abrir /#prueba=CLAVE en incógnito; se retira del URL y se conserva en la sesión. Usar únicamente credenciales y tarjetas de prueba. La firma Webhook valida ID alfanumérico en minúsculas y cuenta/entorno. Para producción establecer environment=production, credenciales renovadas, enabled=true tras pruebas y cobertura validada. No guardar claves en GitHub.
